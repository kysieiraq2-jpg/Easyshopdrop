# Shop&Drop V25.11

Final focused correction for the V25 front-end/mobile test phase.

- Replaced the unreliable mobile datalist behaviour introduced in V25.10 with an explicit searchable dialing-code picker.
- Tapping/focusing the Cellphone or WhatsApp country-code field opens a visible result list.
- Typing a country name, ISO code, or dialing code filters the list (for example Spain, ES, or +34).
- Selected values display the full country name, ISO code and dialing code, e.g. Spain (ES) +34.
- Preserved the already-passed V25.10 Preview Order feedback and all other passed V25.9/V25.10 behaviour.
