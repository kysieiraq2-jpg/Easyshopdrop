# Shop&Drop V25.22 Release Notes

Controlled correction built from the user-tested V25.21 package.

Changes only:
- Homepage Shop by category buttons now load from the existing taxonomy and carry the selected department into Categories & Search.
- Categories & Search now automatically opens and scrolls directly to the department selected on the homepage.
- Subcategory taps now show a clear selected state, including Wine subcategories, while preserving the existing selection confirmation.
- Added lightweight browser prefetch hints for the main navigation destinations to reduce repeat-navigation delay where the browser/network permits.
- No changes to the verified Add Product, List a Service, Pet Services/Pet Supplies, Homemade Food & Pantry, currency, telephone-code, seller-type, dispatching, payment or order structures.
