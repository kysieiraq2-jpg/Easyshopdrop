# Shop&Drop V25.4 Release Notes

## Other Services marketplace clarification
- Renames the customer-facing **Services** area to **Other Services** so it is not confused with services supplied by Shop&Drop itself.
- Confirms Other Services are **free provider listings inside Shop&Drop**, not an external/Google business directory.
- Makes Other Service category cards actionable: selecting a category runs a filtered Shop&Drop service-listing search.
- Adds preview listing results on GitHub Pages so the discovery flow can be tested before the backend is deployed.
- Live search continues to return only approved `service_listings` from the Shop&Drop backend.
- Provider listing remains free; the transparent Shop&Drop marketplace service fee applies to successful paid service transactions.

## Dispatching refinements
- Keeps Dispatching & Transport separate from Other Services.
- Adds clearer weight/dimensions unit guidance.
- Expands the GitHub preview to show a full Dispatch Request Preview summary before future live DR submission/provider matching.

## Scope
- Paid business-directory advertising remains out of scope.
- No Google/external business scraping or automatic directory population is introduced.
