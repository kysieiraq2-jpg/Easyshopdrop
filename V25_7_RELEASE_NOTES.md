# Shop&Drop V25.7

## Mobile testing corrections
- Fixed mobile menu scrolling so the true bottom is easier to reach and removed the duplicate Second-Hand & Pre-Owned main-menu entry; pre-owned browsing remains under Categories & Search.
- Changed ordinary customer-facing SD/ST wording to plain Shop&Drop order/seller wording across checkout, tracking, disputes and dispatching. Internal technical references remain available to backend/admin systems.
- Made Preview order give clear immediate feedback when the preview bag is empty.
- Simplified the customer tracking journey and reserved seller payout stages for seller/admin views. Added explanatory live-state behaviour for current/completed/upcoming stages.
- Added dispute evidence/photo selection and requires a description when Other is selected.
- Expanded the My Account preview with profile, addresses/security/preferences, seller/provider status and sign-out areas.
- Changed customer registration from a hard 12-character minimum to an 8-character minimum with user-friendly guidance. Administrator security remains separate.
- Improved seller/store wording and clarified image URL fields as advanced photo web-link options.
- Retained precise date-and-time availability for services and dispatch requests.

## Backend note
GitHub Pages remains preview-only. Live accounts, uploads, payments, courier booking, order creation, tracking, notifications, disputes and payouts still require the Shop&Drop backend and certified integrations.
