# Shop&Drop V23.1 Release Notes

Focused polish release based on live mobile testing of V23.

## Corrections
- Mobile navigation menu now stays fully inside the phone viewport.
- Search now shows immediate, visible preview feedback on GitHub Pages.
- Admin Control Centre suppresses raw JSON/backend errors in preview mode.
- Operations portal uses professional preview wording and suppresses raw backend errors.
- Administrator portal links are clearer and include transaction tracking.

## Transaction & Order Tracking
- Added customer-facing **Track My Order** portal.
- Added protected administrator **Transaction Tracking** portal.
- Transaction lifecycle covers order placed, payment confirmed, seller preparation, courier handover, in transit, delivered, completion confirmation, seller payout eligibility/payment and transaction completion.
- Administrator tracking is designed to show order/payment references, delivery events, Shop&Drop commission, seller proceeds and payout status without exposing raw card/CVV or seller banking data to unauthorized users.

Live payment, courier and payout actions remain disabled until approved providers and authenticated backend services are connected.
