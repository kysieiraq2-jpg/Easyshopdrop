# Shop&Drop V25.21 Release Notes

Controlled update built from the verified V25.20 baseline.

Changes only:
- Other Services: added prominent OFFER / LIST A SERVICE — FREE route near the top.
- Other Services: service-category cards now expand into service subcategory buttons.
- Seller Centre: List a Service now uses the same service category/subcategory structure.
- Seller Centre: restored/initialized country and currency selectors and added clear labels so the previously blank controls are understandable and functional.
- Product and service location fields are clearly labelled Country, Region/State/Province, City/Area and Currency/Coverage. Region/city remain manual worldwide in this preview; standardized subdivision data is reserved for the live location integration rather than hard-coded incompletely.
- No changes to the verified product Categories/Subcategories system or homepage Shop by category layout.
- Dispatching performance delay remains a recorded follow-up item and is not changed in this release.
