# Shop&Drop V25.13

Final mobile country-code selector correction for the current front-end phase.

- Restores the proven V25.9 native Cellphone and WhatsApp `<select>` dialing-code dropdowns.
- Adds a separate search field immediately above each native dropdown.
- Search accepts country name, ISO country code, or dialing code (for example Spain, ES, or +34) and filters the native dropdown list.
- Keeps Cellphone and WhatsApp selections independent.
- Leaves the previously passed Preview Order feedback and other V25.12 functionality unchanged.
