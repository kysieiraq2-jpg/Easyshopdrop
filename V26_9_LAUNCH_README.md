# Shop&Drop V26.9 Launch File

`index.html` is the GitHub/root launch file for V26.9. It redirects to the operational website at `public/index.html`.

`V26_9_LAUNCH.html` is a version-labelled copy retained for identification/backup. GitHub Pages should continue to use the root `index.html` filename.

V26.9 operational frontend changes are in:
- `index.html` — V26.9 root launch marker/redirect.
- `public/index.html` — consolidated homepage/menu/contact presentation.
- `public/common.js` — consolidated menu/taxonomy/static fallback logic.

The complete V26.9 package retains the full V26 source, audits, database, Supabase, security and integration material.
