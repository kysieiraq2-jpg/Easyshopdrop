# Shop&Drop V25.12

Final correction for the current mobile/front-end testing phase.

- Restores the proven country-code picker interaction for Cellphone and WhatsApp.
- Tapping either country-code control opens the full dialing-code list.
- Adds a search field at the top of that opened list.
- Search accepts country name, ISO country code, or dialing code (for example Spain, ES, or +34).
- Selecting a result closes the picker and keeps Cellphone and WhatsApp selections independent.
- No other previously passed behaviour is intentionally changed.
