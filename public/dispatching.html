How the transaction works

dispatch request → eligible provider option/offer → provider target proceeds + transparent Shop&Drop marketplace service fee → customer sees the agreed total → Shop&Drop order + provider transaction → payment confirmed → unique Arrival PIN issued privately to customer → provider notified → vehicle arrives at agreed location → customer gives Arrival PIN to provider → PIN verified → automatic provider payout initiated subject to payment and security safeguards → feedback.

Live provider matching, payment, location/status integrations and payouts activate only after the certified backend/provider integrations are connected.

Communication & trust

Important events are linked to the same transaction references and can trigger in-site, email, WhatsApp Business or SMS notifications according to verified preferences and provider availability. Routine transactions are automated; Admin handles exceptions.
