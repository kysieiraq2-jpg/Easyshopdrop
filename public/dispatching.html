How the transaction works

dispatch request → eligible provider option/offer → provider target proceeds + transparent Shop&Drop marketplace service fee → customer sees the agreed total → Shop&Drop order + provider transaction → payment confirmed → provider notified → job status updates → completed → customer may confirm or report a problem → automatic completion after the protection period if no qualifying dispute is open → provider payout eligible → provider paid.

Live provider matching, payment, location/status integrations and payouts activate only after the certified backend/provider integrations are connected.

Communication & trust

Important events are linked to the same transaction references and can trigger in-site, email, WhatsApp Business or SMS notifications according to verified preferences and provider availability. Routine transactions are automated; Admin handles exceptions.
