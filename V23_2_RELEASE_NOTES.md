# Shop&Drop V23.2

Focused polish release based on V23.1 phone testing.

- Customer tracking now separates Seller payout eligible and Seller paid into distinct lifecycle stages.
- Preserves V23.1 mobile menu, search preview feedback, Seller Centre preview handling and admin/operations preview error handling.
