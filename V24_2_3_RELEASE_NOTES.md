# Shop&Drop V24.2.3 — Category Navigation Refinement

- Main product categories are shown alphabetically A–Z.
- Product listing now uses a two-step Main Category → Subcategory selector.
- Subcategories are shown only after a main category is selected and are alphabetically sorted.
- Product condition remains separate: New, Like New, Used / Pre-Owned, Refurbished.
- Uses the existing shared master taxonomy; no duplicate second-hand catalogue is created.
- Preserves the V24.2.2 handmade furniture taxonomy and all prior V24.1 marketplace features.
