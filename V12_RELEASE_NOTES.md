# Version 12 release notes

Version 12 moves Easy Shop & Drop SA toward a real consumer marketplace experience.

### Added
- Polished responsive marketplace storefront
- Category navigation and search
- Product cards with ratings/review counts
- Persistent server-side cart
- Wishlist
- Customer address storage
- Product detail API with reviews
- Verified-purchase review rule
- Seller store profile and public store API
- Seller profile editing
- Seller product images/SEO-friendly SKU fields in schema
- Expanded customer/account flow
- Admin and seller areas linked from marketplace
- PostgreSQL tables for new marketplace features

### Still required before public launch
- Real image upload/storage (S3-compatible object storage)
- Real payment provider credentials and production webhook verification
- Courier integration
- Email/SMS services
- Full address/checkout UI
- Returns/refunds/chargebacks
- Seller KYC and settlement reconciliation
- POPIA/CPA/ECT/tax/VAT legal review
- Rate limiting, WAF, monitoring, security testing and backups
