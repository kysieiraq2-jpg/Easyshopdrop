# Shop&Drop V25.2

- Applies the same transparent marketplace service-fee model to once-off/bookable services as to products.
- Service providers enter the amount they want to receive per pricing unit.
- Shop&Drop calculates and displays the marketplace service fee and final customer rate before submission.
- Static GitHub Pages preview uses the same V25.1 progressive test schedule for testing.
- Live backend snapshots provider target proceeds, Shop&Drop service fee, and published customer rate per unit.
- Service booking preview preserves those listing-time snapshots instead of recalculating a hidden deduction later.
- Current fee tiers remain configurable testing rates, not permanent commercial rates.
