# Shop&Drop V25.1 — Initial Service-Fee Test Schedule

- Adds the first configurable progressive Shop&Drop Marketplace Service Fee schedule for testing.
- Seller target proceeds remain unchanged; the service fee is added to create the published customer price.
- Test tiers: first R1,000 at 8%; R1,001–R5,000 at 6.5%; R5,001–R20,000 at 5%; above R20,000 at 4%.
- R10 minimum service fee on positive amounts.
- GitHub Pages Seller Centre preview now calculates the same fee locally so mobile testing shows real figures before backend deployment.
- Live backend continues to read fee tiers from the database, keeping the schedule configurable.
- These are test rates, not a permanent tariff; revise after unit-economics, tax, provider and real transaction testing.
